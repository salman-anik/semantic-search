Anik is currently working on an academic Natural Language Processing project titled "Self-Supervised Semantic Search Using Contrastive Representation Learning.
" The project aims to create a semantic search system that understands the meaning of a user's query and retrieves documents that are conceptually relevant.
Traditional keyword search may fail when a query and a document use different words to express similar ideas.
Semantic search attempts to solve this problem by representing sentences or documents as numerical vectors called embeddings.
These embeddings can be compared using similarity measures to identify content with related meanings.
For example, a user might search for "ways to learn programming" while a document contains the phrase "a beginner's guide to software development.
" A semantic search engine should recognize the conceptual relationship between these expressions even though their wording differs.
The semantic search project explores sentence embeddings, contrastive representation learning, self-supervised learning, similarity measurement, and document retrieval.
Contrastive learning involves learning representations that bring related examples closer together and distinguish less-related examples.
Self-supervised learning uses relationships or signals derived from data to support training without requiring every example to have a manually assigned label.
The project intends to use Python and Sentence Transformers to generate sentence embeddings and a Gradio interface to provide a user-friendly search experience.
The system will accept a text query, compare it with a collection of documents, rank the documents according to semantic similarity, and display the most relevant results.
Anik is developing this project with two other university students, making a team of three.
The expected development timeline is two to three months.
As a beginner in NLP, he wants to follow a practical roadmap, understand each stage of implementation, test the system with different queries, and evaluate whether the retrieved documents are relevant.
